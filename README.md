# TechLink Solutions: Azure Cloud Migration & Infrastructure Project

## Overview
This repository contains a comprehensive cloud migration project for **TechLink Solutions**, a mid-sized tech company transitioning from an on-premises data center to **Microsoft Azure**.

The project bridges high-level strategic planning with hands-on technical implementation. It is split into two core components:
1. **Strategic Cloud Migration Plan:** Evaluating organizational readiness, designing cloud security architecture, and mapping out a phased migration strategy.
2. **Practical Cloud Infrastructure Deployment:** Building and securing a live Azure network environment, configuring encrypted databases, setting up high availability, and deploying application workloads using Docker containerisation.

---

## Purpose of the Project
The primary objective of this project is to simulate a real-world enterprise cloud transformation. It demonstrates how to take a growing business facing hardware limits, traffic surges, and legacy security controls, and systematically transition its infrastructure into a secure, resilient, and scalable cloud environment.

---

## What You Will Learn & Gain

### 1. Cloud Architecture & Strategy Design
* **Readiness Assessment:** Evaluate legacy IT environments, business drivers, and organizational gaps to determine cloud migration readiness.
* **Migration Frameworks:** Formulate end-to-end adoption roadmaps, choosing appropriate deployment models (IaaS/PaaS) and service providers.
* **Governance & Risk Management:** Identify security vulnerabilities, regulatory requirements, and change management strategies for staff upskilling.

### 2. Hands-On Infrastructure & Security Engineering
* **Virtual Network Design (VNet):** Architect isolated multi-subnet environments using Network Security Groups (NSGs) to enforce strict traffic rules and zero-trust principles.
* **Data Security & Encryption:** Implement database solutions in Azure with full **Encryption at Rest** and **Encryption in Transit (TLS)**, secured via Private Endpoints or service isolation.
* **High Availability & Threat Mitigation:** Deploy Azure Load Balancers / Application Gateways to manage traffic surges and enable Azure DDoS Protection to safeguard workloads against malicious traffic.
* **Containerisation with Docker:** Package web applications into Docker containers, deploy them across Azure Virtual Machines, and establish secure inter-container and database networking.

This project incorporates the deliverables and solution documents for both key milestones:
